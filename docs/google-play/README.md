# Публикация essola в Google Play

## Файл приложения

Google Play принимает только файл **AAB** (Android App Bundle), а не APK.

Как собрать: GitHub → Actions → **Android APK** → Run workflow, отметить **«Файл AAB для Google Play»** → Run.
Через 15–25 минут ссылка придёт в задачу «📱 Essola в Expo Go» с заголовком «Google Play: файл для публикации (AAB)».

Пакет приложения — `com.essola.lab`, номер версии растёт сам.
При первой загрузке Google предложит **подписание приложений в Google Play (Play App Signing)** — соглашайтесь.

## Пошагово в Play Console (play.google.com/console)

1. **Создать приложение:**
   - название «essola: сканер состава косметики»;
   - язык по умолчанию — русский;
   - тип — приложение;
   - бесплатное.
2. **Тестирование.** Для новых личных аккаунтов Google требует закрытое тестирование: **не меньше 12 тестировщиков в течение 14 дней**.
   - Тестирование → Закрытое тестирование → создать трек;
   - добавить почты тестировщиков (Google-аккаунты);
   - загрузить AAB.
   - Тестировщики ставят приложение по ссылке и открывают его хотя бы раз в несколько дней.
   - После 14 дней — «Подать заявку на рабочую версию».
3. **Страница в магазине** (Основная страница). Тексты — как для RuStore, в `docs/rustore/README.md`:
   - краткое описание — до 80 символов;
   - полное описание.
   - Иконка 512×512 — `docs/rustore/icon-512.png`.
   - Картинка 1024×500 — `docs/google-play/feature-1024x500.png`.
   - Скриншоты телефона — от 2 до 8 штук.
4. **Политика конфиденциальности:** `https://functions.yandexcloud.net/d4eikcrvo6v275frt26v?doc=privacy`
5. **Доступ к приложению:** «Все функции доступны без особого доступа». Вход необязателен: сканер, база и конструктор работают без аккаунта.
6. **Реклама:** нет.
7. **Возрастные ограничения:** анкета IARC. В приложении есть общение пользователей (форум, комментарии) с модерацией и жалобами; насилия, азартных игр и продажи товаров нет.
8. **Целевая аудитория:** 18+. Так приложение не попадает под правила для детских приложений.
9. **Категория:** «Красота».
10. **Безопасность данных** (Data safety) — ответы ниже.

## Безопасность данных (Data safety)

- **Собирает ли приложение данные:** да.
- **Данные шифруются при передаче:** да (HTTPS).
- **Можно запросить удаление:** да. В приложении: Кабинет → «Удалить аккаунт». На сайте: страница поддержки `…?doc=support`.
- **Передача третьим лицам:** нет. Яндекс Облако — наш обработчик (хостинг), это не передача.

| Тип данных | Собирается | Зачем | Обязательно |
|---|---|---|---|
| Личная информация → Адрес эл. почты | да | Управление аккаунтом | нет (только при входе по почте) |
| Личная информация → Имя | да | Управление аккаунтом | нет |
| Фото и видео → Фото | да, обрабатывается мгновенно (не хранится) | Функции приложения (распознавание состава) | нет |
| Действия в приложении → Другой пользовательский контент (сообщения форума, рецепты, отзывы) | да | Функции приложения | нет |
| Идентификаторы устройства → случайный ID приложения | да | Функции приложения, защита от злоупотреблений (дневные лимиты) | да |

Не собирает: местоположение, контакты, финансовые данные, здоровье, аудио, файлы, историю браузера.

## Разрешения

Приложение просит только **камеру** (сканер состава и штрихкодов). Если Google спросит зачем — «камера нужна, чтобы сфотографировать состав на упаковке или считать штрихкод».

## Обновления после публикации

- Обычные изменения приходят людям через действие «Выпустить обновление», без новой проверки в магазине.
- Новый AAB нужен только при «нативных» изменениях: новые модули, разрешения, иконка.
- Оплата и баллы в Google Play — только через оплату Google. План в `docs/monetization.md`, пока не включено.
