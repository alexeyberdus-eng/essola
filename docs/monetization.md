# Баллы essola

**С 13.10.2026 работают дневные баллы ★ (решение владельца):** 20 баллов в день бесплатно, сгорают в конце дня
(по Москве). Фото состава 3, технолог в конструкторе 3, в сравнении 3, фото этикетки 1; остальное бесплатно.
Пакеты: 100 — 199 ₽, 200 — 299 ₽, 300 — 399 ₽ (`PACKS` на сервере). **С 14.10.2026 покупка через ЮKassa готова** в версии
1.1.0 для RuStore (Android): платёж создаёт сервер (`pay.create`), баллы начисляются только после проверки платежа
запросом к ЮKassa (`ykSettle`, уведомление на адрес сервера или проверка при открытии «Баллов»). Купленные баллы —
в аккаунте (`wallet/<uid>.json`), не сгорают, тратятся после дневных. Google Play и iPhone — без ЮKassa.

## Исходный план

Включаем только после публикации в App Store, отдельной версией приложения, которая проходит проверку магазина.
Никакого скрытого включения через сервер.

## Правило

- **Бесплатно** — всё, что работает по нашей базе: поиск, карточки, оценки, подбор, фильтр по ингредиенту,
  сравнение (цифры и сводка), штрихкод и «Честный знак» из базы, ссылки на магазины (страницу читает телефон),
  конструктор и его проверки, пометки ЕС, рецепты, форум.
- **«Что даёт средство»** — бесплатно: стоит ~0,15 ₽, ответ сохраняется для всех.
- **За баллы** — всё, что вызывает ИИ. Списываем только когда ИИ действительно отработал:
  ответ из сохранённого (чужой скан, та же формула, та же пара) — бесплатно; ничего не нашлось — бесплатно.
- Чтобы сканер работал без покупки: 20 баллов в подарок при регистрации и 2 бесплатных скана фото в день.

## Магазины

- iPhone: баллы только через покупки Apple (расходуемые покупки). Купленные на Android баллы можно тратить на iPhone,
  если на iPhone их тоже можно купить через Apple.
- RuStore: ЮKassa.
- Google Play: оплата Google для цифровых товаров — решим при публикации там.
- Баланс, списание и правила — только на сервере.
