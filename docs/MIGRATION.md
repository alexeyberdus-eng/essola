# Переезд: Timeweb + ChatGPT через VDSina

Схема:

```
Телефон → основной сервер Timeweb (Россия)        → пересылка VDSina (Нидерланды) → ChatGPT
          база, аккаунты, лимиты, кеш, страницы      только передаёт вопрос к ИИ
                                                  → GigaChat / Яндекс — запасные, если ChatGPT не ответил
```

Личные данные (аккаунты, почты) остаются в России. За границу уходит только текст состава, формулы и фото
этикетки.

Ключи и пароли **не присылайте в чат**: только в GitHub → репозиторий essola → Settings → Secrets and variables →
Actions → New repository secret.

---

## Шаг 1. ChatGPT (делает друг в Канаде)

1. platform.openai.com → войти или зарегистрироваться.
2. Settings → Billing → добавить карту и пополнить баланс на $10–20. Включить лимит расходов (Limits), например $30 в
   месяц.
3. API keys → Create new secret key → назвать `essola` → скопировать ключ (начинается с `sk-`).
4. Положить ключ в GitHub-секрет **`OPENAI_API_KEY`**.

## Шаг 2. Пересылка: сервер VDSina

1. vdsina.ru → создать сервер:
   - локация **Нидерланды (Амстердам)**;
   - система **Ubuntu 24.04**;
   - самый дешёвый тариф (1 ядро, 1 ГБ — достаточно).
2. После создания придут IP и пароль root.
3. GitHub-секреты:
   - **`RELAY_HOST`** — IP сервера (например `185.12.34.56`);
   - **`RELAY_PASSWORD`** — пароль root (или **`RELAY_SSH_KEY`** — приватный SSH-ключ, если добавляли ключ).

## Шаг 3. Основной сервер Timeweb

**Отдельный сервер только для essola.** На другом сервере Timeweb владельца работает дашборд WB/Ozon (Caddy, Python) —
его не трогаем: выкладка сама останавливается, если видит Caddy.

1. Панель Timeweb → ваш сервер: проверьте, что локация **Россия**, система Ubuntu 22.04 или 24.04, памяти **не меньше
   4 ГБ** (база средств держится в памяти).
2. GitHub-секреты:
   - **`TIMEWEB_HOST`** — IP сервера;
   - **`TIMEWEB_PASSWORD`** — пароль root (или **`TIMEWEB_SSH_KEY`** — приватный SSH-ключ).

## Шаг 4. Напишите в чат «секреты готовы»

Дальше всё делает Claude:

1. Запускает «Пересылка к ChatGPT» — ставит nginx и HTTPS на VDSina и проверяет, что ChatGPT отвечает.
2. Запускает «Сервер на Timeweb»:
   - ставит Node и nginx;
   - переносит все данные из свежей резервной копии;
   - включает HTTPS по адресу `<IP-через-дефисы>.sslip.io`;
   - проверяет сканер, базу и ИИ.
3. Проверяет ответы ChatGPT на настоящих составах и фото.
4. Переключает приложение на новый сервер (одна строка в `.github/scan-url`):
   - Expo Go — сразу;
   - RuStore — через «Выпустить обновление», по вашей команде.

## Что пока не переедет

- **Вход по почте с кодом:** письма отправлял Яндекс (Postbox). Нужен другой почтовый сервис (например, почта
  Timeweb или Unisender) — сделаем отдельно. Вход через VK работает.
- **Поиск состава в интернете** (Yandex Search API) — без Яндекса не работает. Остальное (база, ссылки на магазины,
  сканер) работает.

## Риски

- OpenAI не обслуживает Россию: аккаунт могут закрыть. Тогда сервер сам переходит на GigaChat (секрет
  `GIGACHAT_KEY`), а при его отсутствии — на Яндекс.
- Домен `sslip.io` временный. Позже можно направить `api.essola.ru` на сервер Timeweb — nginx уже ждёт это имя.

## Где что лежит

| Что | Где |
|---|---|
| Код сервера | `server/yandex-scan/index.js`, запуск на своём сервере — `server.js` |
| Выкладка основного сервера | `.github/workflows/deploy-timeweb.yml` (запуск: правка `.github/timeweb.trigger`) |
| Выкладка пересылки | `.github/workflows/deploy-relay.yml` (запуск: правка `.github/relay.trigger`) |
| Настройки на сервере | `/etc/essola.env` (из секретов GitHub), данные — `/srv/essola/data` |
| Адрес сервера для приложения | `.github/scan-url` |
