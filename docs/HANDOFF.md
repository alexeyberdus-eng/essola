## 2026-10-06 · Claude

### Сделано (по аудиту Codex от 05.10, `AUDIT-2026-10-05`)
- **Права на сервере (п.1).** Действия с профилем, рецептами, форумом, лайками, подписками и уведомлениями
  определяют автора через функцию `actor()`:
  - вошедший пользователь — по сессии;
  - гость — по своему id и секрету устройства `essola.secret`. Первый запрос с секретом закрепляет id
    (`owners/<sha(id)>.json`).
  - id аккаунта (`a…`) без сессии не принимается.
  - Страница админки больше не содержит ключ приложения; без ключа пропускаются только админские режимы.
- **Изоляция аккаунтов (п.2).** При выходе личные данные сначала уходят в аккаунт, потом стираются с телефона
  (`clearPersonalData`), и приложение перезапускается. В облако отправляются только списки текущего владельца
  (`setSyncOwner`).
- **Лимиты (п.3).** Каждый платный вызов сначала записывает свою отметку
  (`limits/<день>/<кто>/<вид>/<время>.json`), потом считает отметки; выигрывают самые ранние. Если хранилище
  недоступно — отказ.
- **Подбор товара ИИ (п.4)** идёт через свой лимит `pick` и запоминается (`pick/…`).
- **Общая база (п.5).** Составы с телефонов (`barcode.save`, `save`, скан с штрихкодом) не перезаписывают чужие
  записи:
  - первая правдоподобная запись получает метку «не подтверждено»;
  - такой же состав от другого человека её подтверждает;
  - отличающийся состав только пишется в журнал `suggest/`.
  - Правдоподобие проверяется по CosIng и русским названиям.
- **Удаление аккаунта (п.6)** сообщает об успехе только после ответа сервера; при ошибке можно повторить.
- **Размер входа (п.7).** Поля запросов к ИИ обрезаются; у фото проверяются реальные размеры в пикселях
  (`imageOk`).
- **Одинаковые запросы (п.8):** одновременные одинаковые запросы внутри одного экземпляра функции делают один
  вызов модели (`shared`).

### Другое
- **Технолог в конструкторе:**
  - отвечает строкой «О:» (что получится, для чего, кому) и «В:» (вывод);
  - в приложении это блоки «Что получится» и «Вывод»;
  - подсказка про 100% больше не стирает вывод.
- **Вход:** обязательная галочка согласия на обработку персональных данных; время согласия хранится в аккаунте
  (`consentAt`).
- **Истории:** удержание пальца ставит на паузу.
- **Сборка для Google Play (AAB):** в действии «Android APK» новая галочка «Файл AAB для Google Play».
  Инструкция в `docs/google-play/README.md`.
