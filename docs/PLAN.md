# Планы и советы (сохранено по просьбе владельца)

## Выпуск в App Store
1. Первая версия — без оплат и без клуба: проверка Apple проходит проще.
2. Нужен аккаунт разработчика Apple → проверить распознавание текста на самом телефоне (сканер без ИИ, дешевле), затем сборка и отправка на проверку.
3. Перед отправкой: страницы «Политика конфиденциальности» и «Поддержка» на essola.ru, уведомление в Роскомнадзор об обработке персональных данных.
4. После сборов баз — сделать репозиторий на GitHub приватным.

## Оплата и Essola Club (версия 1.1, после первого одобрения)
- Сейчас: заключить договор с ЮKassa (на ИП), подать в Apple заявку на External Purchase Link для российского App Store (комиссия 27%, ссылка видна только пользователям из России).
- Клуб = живой технолог 1:1 + бонусы. Расширенные лимиты и другие цифровые бонусы — только через одобренную ссылку Apple или через сайт.
- Включать оплату только новой версией через проверку Apple, не тихим обновлением (за это удаляют приложение).
- Не выдавать цифровые покупки за «формальность» — это нарушение правил Apple.
- Физические товары (магазин Essola) можно оплачивать своей кассой.

## Расходы
- Лимиты: 50 в день каждого платного вида на аккаунт/телефон (описания — 200), на IP — вчетверо больше. Менять — переменная `DAILY_LIMIT`.
- Ответы ИИ запоминаются по составу, повтор бесплатный.
- Поиск средств: сначала наши базы и «Честный знак», ИИ и интернет — в последнюю очередь.
- Расходы смотреть в веб-панели: https://functions.yandexcloud.net/d4eikcrvo6v275frt26v?admin (пароль — секрет `ADMIN_TOKEN` в GitHub).
