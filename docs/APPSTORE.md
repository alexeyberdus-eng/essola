# Выход в App Store — пошагово

Кто что делает: **[вы]** — шаги в ваших аккаунтах (мне туда доступа нет и не нужно), **[я]** — сборка, загрузка и настройки в коде.
Ключи, пароли и файлы `.p8` — только в GitHub Secrets, никогда в чат.

## 1. Аккаунт разработчика Apple — [вы]

1. **Apple ID с двухфакторной защитой.** Лучше отдельный «рабочий» Apple ID (например, на почту hello@essola.ru, когда появится ящик), но можно и личный.
   Настройки iPhone → ваше имя → «Вход и безопасность» → «Двухфакторная аутентификация» должна быть включена.
2. **Приложение Apple Developer** (из App Store) → вкладка «Учётная запись» → **Enroll Now / Зарегистрироваться**.
   - Тип: **Individual (физлицо)**. ИП для Apple — это физлицо, в магазине продавцом будет указано ваше имя.
     Если нужно, чтобы продавцом значилась «Essola» — нужен ООО + номер D-U-N-S (бесплатно, 1–2 недели), тогда тип Organization.
   - Данные — как в паспорте, латиницей.
3. **Оплата 99 $ в год.** Российские карты Apple не принимает. Варианты: карта банка другой страны (например, Казахстана, Киргизии), или оплатить через знакомого с иностранной картой. Оплата идёт в приложении Apple Developer.
4. Ждать подтверждения: обычно от нескольких часов до 2 дней. Придёт письмо «Welcome to the Apple Developer Program».

## 2. App Store Connect — [вы], 15 минут

1. Зайти на **appstoreconnect.apple.com** → «Приложения» → «+» → «Новое приложение»:
   - Платформа: iOS
   - Название: **essola lab** (должно быть свободно в App Store; запасные: «essola — сканер косметики», «essola: состав косметики»)
   - Основной язык: русский
   - Bundle ID: **com.essola.lab** (если его нет в списке — я создам при первой сборке)
   - SKU: `essola-lab-1`
2. **Ключ для автоматической загрузки** (чтобы я собирал и отправлял сборки сам):
   «Пользователи и доступ» → «Интеграции» → «Ключи App Store Connect» → «+» → имя `essola-ci`, доступ **App Manager** → скачать файл `AuthKey_XXXX.p8` (скачивается один раз!).
   Записать: **Issuer ID** (вверху страницы) и **Key ID**.
3. Положить в GitHub → Settings → Secrets → Actions:
   - `ASC_ISSUER_ID` — Issuer ID
   - `ASC_KEY_ID` — Key ID
   - `ASC_KEY_P8` — всё содержимое файла `.p8` (открыть в «Текстовом редакторе», скопировать целиком)
   - `APPLE_TEAM_ID` — Team ID (developer.apple.com → Account → Membership details)
   - `EXPO_TOKEN` — expo.dev → аккаунт → Access tokens → Create (если ещё не лежит)

## 3. Сборка и TestFlight — [я]

- Сборка iOS в облаке Expo (EAS Build) через GitHub Actions, отправка в App Store Connect (EAS Submit).
- Сборка появится в TestFlight через 15–30 минут → вы ставите приложение TestFlight на iPhone и проверяете настоящую версию (не Expo Go): распознавание текста на телефоне, вход через Apple, камера.

| Что | Кто |

| Описание, подзаголовок (30 символов), ключевые слова (100 символов) | [я] напишу |
| Ссылка поддержки и политика конфиденциальности (страницы на essola.ru) | [я] подготовлю тексты, [вы] публикуете на сайте |
| Возрастной рейтинг (анкета) | [вы] по моей подсказке: «пользовательский контент — да, с модерацией» → 12+ |
| «Конфиденциальность приложения» (какие данные собираем) | [вы] по моей таблице: почта/имя (аккаунт), фото (не сохраняем), контент пользователей, идентификатор устройства |
| Шифрование | уже указано в коде: только стандартный HTTPS |
| Заметки для проверяющего | [я] напишу: как войти (через Apple), где форум, жалобы и удаление аккаунта |

## 5. Отправка на проверку — [вы] одна кнопка

App Store Connect → приложение → версия 1.0 → выбрать сборку → «Отправить на проверку». Проверка обычно 1–3 дня.
Частые причины отказа и что у нас уже есть:
- Вход через сторонний сервис (VK) без «Войти с Apple» — **есть**.
- Удаление аккаунта внутри приложения — **есть**.
- Жалобы и блокировка в пользовательском контенте — **есть**.
- Цифровые покупки мимо Apple — **в первой версии оплат нет**.
- Медицинские обещания («лечит», «диагностирует») — тексты держим информационными, дисклеймер есть.
