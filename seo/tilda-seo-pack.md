## 3. Семантика страницы арганового масла

Эти запросы нужно естественно вписать в H2 и текст. Повторять каждый 1–2 раза, без переспама.

- **Основные:** аргановое масло, аргановое масло купить, аргановое масло натуральное, нерафинированное аргановое масло
- **По назначению:** аргановое масло для волос, для лица, для тела, для ногтей и кутикулы, для ресниц
- **Информационные (хорошо закрывать в FAQ):** как применять аргановое масло, аргановое масло для жирной кожи, можно ли наносить на ночь, как отличить подделку, чем аргановое масло отличается от косметического
- **LSI-слова:** холодный отжим, аргания, Марокко, витамин E, токоферол, жирные кислоты, олеиновая, линолевая, комедогенность, без отдушек

### Рекомендуемая структура страницы (H2)
1. H1 + первый экран: польза, объём, кнопки WB / Ozon / Лэтуаль
2. H2 «Чем полезно аргановое масло»
3. H2 «Как применять» — отдельные H3 для волос, лица, тела и ногтей
4. H2 «Состав и характеристики» — таблица: INCI `Argania Spinosa Kernel Oil`, способ отжима, страна, объём, срок годности
5. H2 «Как отличить настоящее аргановое масло»
6. H2 «Отзывы» — ссылки на реальные отзывы на маркетплейсах
7. H2 «Частые вопросы» — блок FAQ (разметка ниже)
8. H2 «Где купить»

Объём текста — 1500–2500 слов на странице товара. Тексты пишите в обычных текстовых блоках, а не на картинках: поисковики не читают текст на изображениях.

## 4. Микроразметка Schema.org

Вставляется в блок **T123 (HTML-код)** в самом низу страницы. Цены и наличие указывайте реальные. Рейтинг (`aggregateRating`) добавляйте, только если отзывы опубликованы на самом сайте. Иначе Яндекс и Google могут наложить санкции.

### Organization — для главной страницы
```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "ESSOLA",
  "url": "https://[домен]/",
  "logo": "https://[домен]/[logo.png]",
  "sameAs": [
    "https://www.wildberries.ru/catalog/436643513/detail.aspx",
    "https://www.ozon.ru/product/essola-naturalnoe-arganovoe-maslo-dlya-litsa-tela-i-volos-nerafinirovannoe-pitanie-i-uvlazhnenie-2719749191/",
    "https://www.letu.ru/brand/essola"
  ]
}
</script>
```

## 6. Изображения

- В карточке каждого изображения в Тильде заполните **alt**, например: «Аргановое масло ESSOLA 30 мл в стеклянном флаконе с пипеткой»
- Формат WebP. Вес картинки на первом экране — до 200 КБ, остальных — до 150 КБ
- Название файла латиницей до загрузки: `essola-argan-oil-30ml.webp`, а не `IMG_2231.jpg`
- 360°-флакон: первый кадр — обычный `<img>` с alt, чтобы его видели поисковики (так уже сделано в демо `demo/hero-3d`)

---

## 7. Скорость и Core Web Vitals

- Цели: LCP < 2,5 с, CLS < 0,1, INP < 200 мс. Проверка: https://pagespeed.web.dev
- Уберите неиспользуемые блоки и тяжёлые видео-обложки с первого экрана
- Подключайте не больше 2 шрифтов с ограниченным набором начертаний
- Сторонние виджеты (чаты, квизы) загружайте с задержкой или после действия пользователя
- Обложку Zero Block на первом экране сжимайте. Анимации на мобильных отключайте
